OUVERTURE RAPIDE
- Ouvrez index.html à la racine. Cette version est autonome et fonctionne sans charger de fichiers voisins.
- La navigation utilise #weakness, #analyse, #team et #collection.

CODE SOURCE ORGANISÉ
- Le dossier site/ contient la version multi-pages et les fichiers séparés (HTML, CSS, données et JavaScript).
- Cette version est destinée à l'hébergement statique ou à l'ouverture après extraction complète du dossier.

Pourquoi deux versions ?
L'aperçu de fichiers de ChatGPT peut isoler un fichier HTML de ses fichiers CSS/JS voisins. Le index.html racine intègre donc les mêmes ressources directement pour rester fonctionnel dans cet aperçu. Le code source reste, lui, organisé dans site/.

Aucune dépendance externe n'est requise.
